## Relevant Context — Do Not Deviate Without Escalation

Source: insight_engine.md §2.6 (LLM precedence — the governing principle of this story)
Rule: Full deterministic evaluation precedes any LLM call. The engine runs the **entire** pipeline — gates → scoring → adjustments → verdict — to completion before any Claude call. An LLM must **never** be the thing that discovers a candidate violates a rule, and never produces or alters the verdict. The LLM, if used at all, only explains or elaborates on **survivors** of an already-decided verdict. The current "Claude scoring sandwich" (Claude produces the score, the route assigns the verdict from it) is exactly what this story removes.

Source: insight_engine.md §4.1 (pipeline) + §3.8 (verdict bands)
Rule: The engine produces the verdict in Phase 7 by mapping the final adjusted score through the strategy's `verdict_band_set` (monotonic, per-strategy, validated at load by §6.6). Screening uses `EXECUTE/WAIT/PASS`; the labels are opaque strings to the engine, selected by the candidate's `candidate_type`. The route must take the verdict (and score) from the engine's `ResultRecord` — never compute or override them.

Source: insight_engine-migration-plan.md S5.2 (the invocation pattern to mirror)
Pattern: `parse request → resolve strategy id → adapter.produce_candidates(...) → engine.evaluate(candidates, strategy_id, source_app_id="OTA") → return ResultRecord(s)`. No filtering, scoring, or verdict logic in the route. Persistence happens **inside** `engine.evaluate` via the injected OTA-758 sink (fire-and-forget). OTA-759 applies this to `/analyze/*` but is not landed — there is no committed sibling route to copy; construct the call from the adapter + engine public surface.

Source: insight_engine-migration-plan.md S5.3 (this story)
Scope: `/evaluate/structured` follows the same pattern. It loses its inline gate logic and its hardcoded verdict bands. The engine runs to completion before any Claude narrative call; Claude sits strictly downstream of the engine verdict, invoked only on survivors, only for prose.
