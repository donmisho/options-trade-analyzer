## Scope
A read-only catalog browser over `engine_rules` (OTA + SHARED) showing intent, inputs, expected output, phase, and formula-registry status, filterable by phase. It is the single rule source for the "Add from catalog" pickers in OTA-785/786/787. SHARED rules are selectable for binding but read-only as rules.

## Acceptance criteria
- Lists rules with intent, inputs, output, phase, and whether the rule's `formula:<name>` has a registered implementation.
- Filterable by phase (gate / score / adjustment) so each tab's picker shows only compatible rules.
- SHARED rules shown and selectable for binding, but read-only (no edit/delete of the rule).
- Feeds the three tabs' "Add from catalog" pickers — no separate rule source.

## Out of scope
- Editing rules (the catalog is read-only; rule CRUD lives in OTA-782's API and is not surfaced as a rule editor in F13).
- The actual junction-binding action (the tabs perform the add; the catalog supplies the choice).
