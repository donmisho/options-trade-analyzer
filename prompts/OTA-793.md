## Relevant Context — Do Not Deviate Without Escalation

**Source: insight-agent-migration-plan.md v4 (acceptance reframe) + OTA-793 ticket**
Acceptance is **functional, not parity**. Tests verify **behavior** (every interaction fires the expected action), **field type**, and **formatting** per UI-GUIDANCE. **Tests never assert verdict values** — verdict accuracy is handled downstream (the Export MD path / OTA-507), not here.

**Source: CLAUDE.md → House Style + UI-GUIDANCE.md (the compliance target)**
- Dark-theme CSS variables only, from `web/src/styles/tokens.js` — never inline hex.
- No `$` on any monetary value.
- Scores (0–100): `##.00`. Probabilities and IV rank: `##.00%`. Config percentages: `##%` (no decimals).
- Dates: `mm-dd-yyyy` via `formatDate()` from `web/src/utils/formatDate.js`.
- `var(--bg2)` (#161b22) is permitted **only** on: QuoteBar, filter bars, calculation inset boxes, signal check boxes, risk budget boxes, and key-level callout boxes in Claude's Read. **Never** on: table rows, table headers, expansion panels, group headers, section backgrounds, or any full-width band. (UI-GUIDANCE.md Part 3a)
- Buttons sized to content, never full-width.
